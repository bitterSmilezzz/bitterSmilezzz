## 🛠 代表作

- **[dsh-model-selector](https://github.com/bitterSmilezzz/dsh-model-selector)** ⭐ TypeScript
  DeepSeek Harness (DSH) 的增强模型选择器：单层菜单（搜索 + 分组）+ 底部内联推理强度（Effort）滑杆。

- **[knowflick](https://github.com/bitterSmilezzz/knowflick)** ⭐ Swift
  macOS 冷知识卡片应用：打开即学，左右划卡。SwiftUI 原生实现，支持 AI 自动生成新卡（DeepSeek 等 OpenAI 兼容端点），历史记录 + 延伸阅读链接。

- **[AgentIsland](https://github.com/bitterSmilezzz/AgentIsland)** Swift
  Agent 会话灵动岛监控器 — macOS 菜单栏常驻，QQ 式贴边隐藏 + Token 用量统计。

- **[dsh-asr-voice](https://github.com/bitterSmilezzz/dsh-asr-voice)** JavaScript
  开口即成文 · Speak-to-prompt for DeepSeek Harness：云端 ASR 语音识别 + 提示词优化 + 填入草稿/自动发送，跨平台 macOS / Windows。

- **[dimagent-login-fix](https://github.com/bitterSmilezzz/dimagent-login-fix)** ⭐ JavaScript
  本地 TLS 桥接：让 DimAgent 桌面端直接使用官方域名 dimagent.cn（应用指纹被网络门控时），无代理、无备用域名、打帖不影响更新。

- **[dsh-plugins](https://github.com/bitterSmilezzz/dsh-plugins)** ⭐ JavaScript
  DSH 插件伞仓库（DSH Plugin Umbrella）— 所有新增插件的共同遵循仓库：承载插件契约（Pi / DSH 官方 / DSH-Store 准入 / dsh-std 协议）+ 按契约自动校验自有插件（GitHub Actions），经验档案按主题归档。
